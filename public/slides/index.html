01 · Bağlam

ALO 124 nedir?

ALO 124, Türkiye İstatistik Kurumu (TÜİK)’nun resmi çağrı merkezi hattıdır. Bu slaytlar eğitim bağlamı için özetler; kurum adına resmi açıklama değildir.

Vatandaş teması Bilgi talepleri, yönlendirme, kurumsal iletişim.
Anket / CATI Bilgisayar destekli telefonla görüşme; CAWI/CAPI ile birlikte veri toplama.
Karşılama kaydı Veri gizliliği / güvenlik bilgilendirmesi (Karşılama Ses Kaydı).
Mesai Tipik olarak hafta içi 09:00–18:00.

02 · Ses varlıkları

Ses dosyaları ne işe yarar?

  • Kalite: karşılama script’ine uyum
  • Denetim: süreç ve bilgilendirme kontrolü
  • Eğitim: ajan / operatör koçluğu
  • STT girdisi: ASR boru hattının hammaddesi
Privacy-first Lab’de yalnızca sentetik WAV/MP3; gerçek CATI yanıtı yoktur.

03 · Pipeline

Çağrı merkezi → STT akışı

Lab’de bu akış sentetik örneklerle tekrarlanır; gerçek ALO 124 araması yapılmaz.

03 · Pipeline

Ingest & preprocess

  • Ingest: kayıt → depolama, metadata (süre, kanal)
  • Resample: tipik ASR girdisi 16 kHz mono
  • Denoise: hat gürültüsü / echo (dikkatli)
  • VAD: konuşma / sessizlik; boşluk oranı

03 · Pipeline

ASR → postprocess → görselleştirme

ASR / STT Metin + kelime zaman damgası. Lab’de Mock ASR (+ isteğe bağlı Web Speech).
Postprocess Noktalama, normalizasyon; üretimde PII redaksiyonu.
Analytics Süre, konuşma oranı, sessizlik, anahtar kelime (anket, gizlilik, TÜİK, randevu).
UI Dalga formu, transcript tablosu, metrik kartları.

04 · Gizlilik

KVKK ve güvenlik uyarısı

  • Gerçek çağrı kayıtları kişisel veri içerir; işleme hukuki dayanak ister.
  • Üretimde: erişim kontrolü, şifreleme, denetim izi, redaksiyon.
  • Bu lab demo / sentetik ses üretir; gerçek ALO 124 araması yoktur.
Demo ≠ üretim. Lab çıktılarını operasyonel karar veya resmi istatistik olarak kullanmayın.

05 · Lab

Projeyi nasıl çalıştırırsınız?

  1. npm install
  2. npm run samples (ffmpeg gerekir)
  3. npm run dev → http://127.0.0.1:43123
  4. npm run slides veya /slides/index.html

Ücretli API anahtarı gerekmez. Mock ASR çevrimdışı çalışır.

05 · Lab

Uygulamada ne yapacaksınız?

  • public/samples/ içinden örnek seçin veya WAV/MP3 yükleyin
  • Dalga formunu inceleyin ve oynatın
  • “Transcribe et” ile Mock ASR çalıştırın
  • Transcript, kelime zamanlamaları, güven, süre, konuşma oranı, sessizlik ve anahtar kelime kartlarını doğrulayın
